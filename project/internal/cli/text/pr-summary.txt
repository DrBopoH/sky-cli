открыть pull request локальной фичи по регламенту (3.1.4): запушить саму ветку wip/ММДД-ЧЧММ/имя в origin (без force, под тем же именем) и открыть через gh PR в dev с заголовком-резюме. Версию в PR не вписывает: её ставит слияние. Исправление (sky feature --fix) идёт PR в ветку сборки, от которой отведено (3.6.5). Цель ветки (модуль с цепочкой, зерно или сборка, заведено sky feature) уходит блоком sky-target в конец описания PR. Уже открытый PR только обновляется пушем. Нужны origin, gh с входом (gh auth login), чистое дерево и коммиты, которых нет в dev; --base задаёт другую ветку, --draft открывает черновик, --dry только показывает. Адрес PR запоминается в настройках ветки (sky-pr)
