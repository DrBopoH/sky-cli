снять сборку по регламенту (3.6): запустить команды сборки из sky.conf (строки `build = <папка> <команда>`, их может быть несколько — например бэкенд и фронт; идут по порядку, останов на первой ошибке), дождаться успеха и только тогда создать ветку build/ММДД-ЧЧММ от вершины dev. Хвост ветки — коммит с тем же деревом, что у вершины dev; отличается только сообщение «Build N alpha | v1.a1.C+T.hash». Состояние: a (alpha, по умолчанию), b, s, m; своё название — вторым аргументом: sky build s "macro and market data". HEAD остаётся на dev, ветка в dev не вливается; следующее именованное изменение в dev даёт B+1, C=1. Командам доступна переменная SKY_BUILD_VERSION (v1.a1.C+T.hash): её вшивают в бинарь через -ldflags. Без строк build запуск пропускается с пояснением, ветка всё равно создаётся. Нужен dev с именованным коммитом (sky land), чистое дерево, HEAD на dev; одна сборка на R.B. Итог пишется в .sky/foryou/build.md; --dry только показывает план и ничего не запускает; --from R.B.C+T — точка отсчёта
