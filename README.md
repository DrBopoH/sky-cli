# sky

Go-программа, мост между чатом с ИИ-инженером и git-репозиторием проекта. Ты присылаешь патч, sky проверяет его, делает снимок «до», применяет и коммитит. Любой шаг откатывается.

Автор: Δρ.ΒοροΗ. · MorangTong creative studio

> Статус: до первой сборки (`v1.a1`). Устройство и правила: [docs/](docs/).

## Идея

Чат не видит репозиторий, а репозиторий не видит чат. sky даёт каждой стороне то, что ей нужно:

- чату: архив проекта и факты о нём (`sky up`, `sky look`);
- репозиторию: патч в виде zip-архива с целыми файлами (`sky apply`);
- обоим: снимки и откат, чтобы последняя рабочая версия не терялась (`sky rollback`).

Всё служебное лежит в папке `.sky/` в корне репозитория; она в `.gitignore` и в коммиты не попадает.

## Сборка

Нужен Go 1.24 и только стандартная библиотека.

```
cd project
go build -o sky .
```

## Быстрый старт

```
sky init            # один раз на проект: .sky/, sky.conf, ветка dev
sky up              # упаковать проект для чата (архив копируется в буфер)
sky apply           # применить patch*.zip из inbox
sky rollback        # откатить последний патч
```

Папки исходников, inbox и остальное задаются в `.sky/sky.conf`.

## Команды

| Команда | Что делает |
|---|---|
| `sky init` | заводит проект: git, `.sky/`, `sky.conf`, ветка `dev` |
| `sky up` | упаковывает проект для чата |
| `sky look` | обновляет факты о репозитории в `.sky/foryou/` |
| `sky apply` | применяет все патчи из inbox от старых к новым |
| `sky commit` | коммитит ручные правки как запись, которую можно откатить |
| `sky rollback` | возвращает проект на N записей назад |

Подробности и флаги: [docs/CLI.md](docs/CLI.md).
